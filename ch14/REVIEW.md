# 第 14 章复习提纲

结合 [第 14 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 主题 | 关键点 | 易错 |
| --- | --- | --- |
| 成员 vs 非成员 | 对称运算符非成员，`+=`/下标/自增成员 | 改变左操作数的运算符应为成员 |
| IO 运算符 | 友元非成员，返回流引用 | `>>` 必须检查流状态 |
| 相等与关系 | 一起定义，用 `!=` 表达 `!(==)` | `<` 的语义要与容器使用一致 |
| 下标与自增 | 下标两个版本，自增区分前后缀 | 后缀返回旧值副本 |
| 函数对象 | 重载 `operator()`，可带状态 | 与 lambda 互译 |
| 类型转换 | `operator bool` 用于条件 | 标 `explicit` 防止意外转换 |

## 自测

- [ ] 解释为什么 `>>` 里要 `if (input) ... else 置空`。

- [ ] 对一个类写 `operator==`、`operator!=`、`operator<` 并保持一致性。
- [ ] 说明 `explicit operator bool` 解决了什么问题。
