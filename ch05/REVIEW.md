# 第 5 章复习提纲

结合 [第 5 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 语句 | 关键点 | 易错 |
| --- | --- | --- |
| if/else | else 配对最近的 if | 多语句分支必须加花括号 |
| switch | 命中后贯穿执行 | 每个 case 记得 `break`；变量作用域跨 case |
| for/while | 已知次数用 for，读入驱动用 while | 循环内修改条件变量导致死循环 |
| do while | 体至少执行一次 | 条件中不能使用体内声明的变量 |
| break/continue | 跳出当前循环体 | continue 只结束本次迭代 |
| try/catch | 运行期错误显式处理 | 未捕获的异常直接终止程序 |
