# 第 5 章：语句

已核对并整理 5.1–5.25（书页 154–192 / PDF 页 180–218）。知识复习见 [复习提纲](REVIEW.md)。

## 5.1–5.2 空语句与块

`while (condition);` 的分号就是空语句，多数时候是笔误；块 `{}` 可以用在任何需要一条语句的位置，块本身不以分号结尾。

## 5.3 逗号与紧凑写法

把 `if` 两侧重复的语句用逗号运算符合并进条件或递增部分可以少写花括号，但可读性差，不推荐；保持每个分支一条语句加花括号的写法更清晰。

## 5.4 作用域

`(a)` 中 `p` 在 while 条件里声明，块内可用；`(b)` 中 `string::size_type` 每次 `if` 条件才构造……两题的核心都是：条件中声明的变量只在对应控制结构内可见。

## 5.5–5.6 成绩映射

[ex5_05_06.cpp](ex5_05_06.cpp) 用 if/else 阶梯把分数映射成 `A+` 到 `F`，再用条件运算符改写 pass/fail 判定。样例覆盖 100、96、92、88、82、77、71、66、61、55 十档，输出如 `grade 88 -> A- (pass)`、`grade 55 -> F (fail)`。

## 5.7 悬垂 else

else 与最近的未匹配 `if` 配对。书中的例子靠缩进容易误读，写清花括号可以避免歧义。

## 5.8 花括号缺失

`if (grade == 100) feedback = "high"; else feedback = "low";` 若把 else 挂错 if，逻辑反转；多语句分支必须加花括号。

## 5.9–5.12 统计字符

[ex5_09_12.cpp](ex5_09_12.cpp) 用一个循环同时完成三件事：统计元音（大小写都算，5.9 与 5.12）、统计空格、制表符与换行（5.10）、统计 `ff/fl/fi` 字母对（5.11）。对输入 `Fix the flywheel, officer! It fits.` 输出 `vowels: 9, whitespace: 5, ff/fl/fi: 4`，逐字符核对无误。

## 5.13 switch 的 fall-through

书中每段代码的问题都是缺少 `break`：命中一个 case 后会继续执行下一个 case 的语句。需要共享逻辑时用注释标明故意贯穿，其余情况必须写 `break`。

## 5.14 连续重复的单词

[ex5_14.cpp](ex5_14.cpp) 维护当前连续段与历史最长段两个状态。对输入 `how now now now brown cow cow` 输出 `now occurred 3 times in a row`；无重复时输出提示。注意最长段的单词要单独保存，否则会被最后一次扫描的词覆盖。

## 5.15 三个有错的循环

(a) `for (int ix = 1; ix != sz; ++ix)` 当 `sz <= 1` 时条件永不满足，死循环；应改用 `<`。(b) 循环内修改了参与条件的变量 `sz`，长度不断变化；应把目标长度存入别的变量。(c) `ix` 在循环外声明但条件越过数组末尾才停，最后越界；用 `ix != sz` 且不修改 `sz`。

## 5.16 while 与 for

把"读到 42 停止"写成 for 需要把读入放在条件里：`for (; std::cin >> i && i != 42;)`。读入次数不确定时 while 更自然，for 适合已知次数或带递增变量的场景。

## 5.17 前缀比较

[ex5_17.cpp](ex5_17.cpp) 以较短向量的长度为界逐元素比较，`{0,1,1,2}` 是 `{0,1,1,2,3,5,8}` 的前缀时输出确认，否则输出首个不同元素之前就分道扬镳的信息。

## 5.18 do while 的约束

(a) 循环体里声明了条件用到的 `ival`，作用域不足；(b) 条件 `get_response()` 中的变量同理。do while 的条件只能使用循环体之前可见的名字。

## 5.19 询问两串较短者

[ex5_19.cpp](ex5_19.cpp) 用 do while 反复读入两个字符串并打印较短的一个，输入结束时退出。循环体至少执行一次正是 do while 的语义。

## 5.20–5.21 寻找连续重复

[ex5_20.cpp](ex5_20.cpp) 记录上一个词，一旦当前词相同即输出并停止，没有则报告无重复。[ex5_21.cpp](ex5_21.cpp) 只报告以大写字母开头的重复词。小写词仍更新上一个词，再用 `continue` 跳过比较。`Apple apple Apple tree` 不会报告重复，`Apple Apple tree` 则报告 `Apple occurs twice in succession`。

## 5.22 goto 与循环

书中用 `begin:` 标签加 `goto begin` 模拟循环；改写成 for 循环后无需手工维护标签，控制流一目了然。

## 5.23–5.25 除零与异常

[ex5_23_25.cpp](ex5_23_25.cpp) 合并演示三个小题。5.23 直接做整数除法，除数为零时行为未定义。5.24 在除数为零时显式抛出 `std::runtime_error`。5.25 捕获异常、提示后继续读取下一对整数。程序也会在计算 `INT_MIN / -1` 前报告结果超出范围。依次输入 `6 3`、`5 0`、`9 2` 时，程序输出商 2、除零提示和商 4。
