# 第 1 章：开始

本章覆盖练习 **1.1–1.25，共 25 题**。依据本地中文版第五版扫描 PDF 逐页核对：正文书页 1–25 对应 PDF 页 27–51；习题位于书页 5、8、9、11–13、15、16、20–22。

以下题意用摘要表述。代码以 C++11 为基线；数值例题默认输入和运算结果可由相应类型表示。源码中的输入检查是辅助处理，学习重点仍是本章的输入输出、循环和分组。

## 本章先记住什么

| 内容 | 核心认识 |
| --- | --- |
| `main` | 程序入口，返回类型为 `int`；返回 0 表示成功 |
| `#include` | 使用库设施前包含相应头文件 |
| `std::` | 指明名字属于标准库命名空间 |
| `std::cin >> value` | 读取数据，表达式返回输入流；放在条件中检查读取是否成功 |
| `std::cout << value` | 写出数据，返回输出流，所以可以连续使用 `<<` |
| `std::endl` | 换行并刷新输出缓冲区；`'\n'` 只请求换行 |
| `while` / `for` | 先判断条件，再执行循环体；条件一开始为假时执行零次 |
| `=` / `==` | 前者赋值，后者比较是否相等 |
| 连续分组 | 先读第一项；同组累计；换组输出；循环结束补输出最后一组 |

## 编译、运行与输入结束

每个 `.cpp` 都是独立程序。不能把本章所有源码一起链接成一个可执行文件，因为它们各自定义了 `main`。

若终端已配置 GCC，在仓库根目录执行：

```powershell
New-Item -ItemType Directory -Force build/ch01 | Out-Null
g++ -std=c++11 -Wall -Wextra -pedantic ch01/ex1_03.cpp -o build/ch01/ex1_03.exe
.\build\ch01\ex1_03.exe
```

若使用 MSVC，在 Visual Studio 的 **x64 Native Tools Command Prompt** 中编译：

```bat
cl /nologo /EHsc /W4 /utf-8 /std:c++14 ch01\ex1_03.cpp /Fobuild\ch01\ex1_03.obj /Febuild\ch01\ex1_03.exe
```

先创建 `build/ch01`。MSVC 没有 `/std:c++11` 开关，这里用 `/std:c++14` 编译本章的 C++11 代码。也可以使用[仓库首页](../README.md)里的独立 CMake 配置。

对读到输入结束的程序，PowerShell 可通过管道提供完整输入：

```powershell
'3 4 5 6' | .\build\ch01\ex1_16.exe
Get-Content ch01/data/grouped_sales.txt | .\build\ch01\ex1_25.exe
```

若可执行文件在 `Debug` 子目录，相应调整命令路径。Windows 控制台交互输入通常用 `Ctrl+Z` 后按 Enter 结束；Unix 类终端通常用 `Ctrl+D`。这取决于终端环境。书里的 `< infile` 写法可用于 cmd/Bash，PowerShell 这里使用 `Get-Content` 管道。

## 1.6：分号截断了输出链

位置：1.2 节，书页 8 / PDF 页 34。题意：判断下面的输出片段是否合法并修正。

```cpp
std::cout << "The sum of " << v1;
          << " and " << v2;
          << " is " << v1 + v2 << std::endl;
```

**不合法。** 第一行的分号已经结束语句，后两行从二元运算符 `<<` 开始，缺少左操作数。源码排版中的换行没有自动连接语句的作用。

修正方法：删除前两个分号，形成一条完整输出链；或者保留分号，并给后两行各补上 `std::cout`。本题源码采用第一种方法，输入 `3 7` 时输出和为 `10`。

源码：[ex1_06.cpp](ex1_06.cpp)。

## 1.7：块注释不能嵌套

位置：1.3 节，书页 9 / PDF 页 35。题意：故意编写嵌套注释，观察编译错误。

下面是**故意不能编译**的独立例子：

```cpp
/* outer comment
   /* inner comment */
   this is no longer a comment
*/
int main() { return 0; }
```

第一个 `*/` 就结束了块注释，后面的文字和多余的 `*/` 被当作代码。编译器可能报告未知名字、语法错误等；诊断措辞不是本题的固定答案。

修正时去掉内部注释界定符，或者逐行使用 `//`。注释掉一段已有块注释的代码时，逐行添加 `//` 更容易避免这种问题。

本题不加入正常构建目标，文末验证记录单独检查它应当编译失败。

## 1.8：字符串中的注释符

位置：1.3 节，书页 9 / PDF 页 35。题意：判断四条语句是否合法，预测结果并验证。

```cpp
std::cout << "/*";
std::cout << "*/";
std::cout << /* "*/" */;
std::cout << /* "*/" /* "/*" */;
```

| 语句 | 是否合法 | 原因或输出 |
| --- | --- | --- |
| 第 1 条 | 合法 | 输出 `/*`；字符串内部不开始注释 |
| 第 2 条 | 合法 | 输出 `*/`；字符串内部不结束注释 |
| 第 3 条 | 不合法 | 注释被第一个 `*/` 结束，之后的引号无法组成完整字符串 |
| 第 4 条 | 合法 | 去掉两段注释后等价于 `std::cout << " /* ";`，输出四个字符：空格、`/`、`*`、空格 |

第 4 条可以这样分段理解：`/* "*/` 是第一段注释，`" /* "` 是一个字符串，`/*" */` 是第二段注释。字符串里的 `/*` 只是输出字符，不会开启新的注释。

第 3 条的一种修正是直接写字符串 `std::cout << " */";`，或者把整条原语句用 `//` 注释掉。正常源码保留第 1、2、4 条，并额外插入换行，便于观察输出；第 3 条单独做失败验证。

源码：[ex1_08.cpp](ex1_08.cpp)。

## 1.11：打印两个整数之间的闭区间

位置：1.4.1 节，书页 11 / PDF 页 37。题意：读取两个端点，打印其间所有整数。

## 1.14：for 和 while 如何选择

位置：1.4.2 节，书页 13 / PDF 页 39。

两者都能表达一般的条件循环；选择依据是哪个更清楚地表达控制方式。

| 形式 | 适合情形 | 优点 | 注意点 |
| --- | --- | --- | --- |
| `for` | 计数、遍历明确区间 | 初始化、条件、更新集中，循环变量的作用域容易限制 | 控制逻辑很复杂时循环头不易读 |
| `while` | 重复读取直到失败，或次数由过程决定 | 条件直接表达“何时继续” | 计数循环的更新分散，容易漏写 |

例如计数求和用 `for` 很自然，`while (std::cin >> value)` 则清楚表达“只处理成功读到的数据”。执行次数是否预先已知不是语法限制。

## 1.15：主动制造编译错误

位置：1.4.2 节，书页 13 / PDF 页 39；参照书页 14 的说明。题意：分别观察语法、类型和声明方面的诊断。

每次只保留一个错误，修好后再试下一个，避免一处错误引出一串后续诊断。

| 类别 | 故意出错的片段 | 修正 |
| --- | --- | --- |
| 语法 | `return 0` 后缺分号 | 写成 `return 0;` |
| 语法 | `std::cout << "ok" << std::endl:` | 末尾冒号改成分号 |
| 语法 | `std::cout << "ok" std::endl;` | 在 `std::endl` 前补 `<<` |
| 类型 | `int value = "hello";` | 使用匹配的类型或整数初值 |
| 声明 | 定义 `v1` 后却使用 `v` | 统一名字 |
| 声明 | 直接用 `cout`，没有相应声明 | 使用 `std::cout` |

独立类型错误例子：

```cpp
int main()
{
    int value = "hello";
    return value;
}
```

编译器能发现许多形式和类型错误，但通常不知道你的业务意图。例如把求和写成求乘积，可能完全合法，却不符合题意。因此编译通过后还要检查结果。

## 1.16：读取未知个数的整数并求和

位置：1.4.3 节，书页 15 / PDF 页 41。

```cpp
int sum = 0, value = 0;
while (std::cin >> value)
    sum += value;
std::cout << "Sum is: " << sum << std::endl;
```

## 1.17：预测连续计数程序的结果

位置：1.4.4 节，书页 16 / PDF 页 42。题意：分别考虑全部相同和没有重复值的输入。

全部相同，例如 `7 7 7 7`：

```text
7 occurs 4 times
```

全部不同，例如 `1 2 3`：

```text
1 occurs 1 times
2 occurs 1 times
3 occurs 1 times
```

沿用书中固定的 `times` 文案，不额外处理英文单复数。空输入不输出任何分组。

核心是**连续相同的一段**，不是整个输入中的总次数。例如 `1 2 1` 会输出三组：`1` 一次、`2` 一次、`1` 一次。要让每个值只出现一个汇总，需要先聚在一起，或以后使用关联容器。

## 1.18：运行并验证计数程序

位置：1.4.4 节，书页 16 / PDF 页 42。题意：实际运行 1.17 的两类输入。

```cpp
int current = 0, value = 0;
if (std::cin >> current) {
    int count = 1;
    while (std::cin >> value) {
        if (value == current) {
            ++count;
        } else {
            std::cout << current << " occurs " << count << " times" << std::endl;
            current = value;
            count = 1;
        }
    }
    std::cout << current << " occurs " << count << " times" << std::endl;
}
```

先读取第一个数是为了建立真实的当前分组，并让计数从 1 开始。遇到不同值时，输出旧分组，再用新值开始一组。

**最后一条输出不可省略。** 最后一组之后没有“下一个不同值”触发 `else`，必须在循环结束后输出它。

可自行测试 `7 7 7 7`、`1 2 3`、`1 1 2 1`、单个数和空输入。预期结果见上一题；最后两种分别输出一组和零组。

源码：[ex1_18.cpp](ex1_18.cpp)，也供 1.17 的预测验证使用。

输入：

```text
0-201-78345-X 3 20.00
0-201-78345-X 2 25.00
```

输出：

```text
0-201-78345-X 5 110 22
```

总额 `3*20 + 2*25 = 110`，均价 `110/5 = 22`。**不能直接求两个单价的算术平均**：每条记录的销售册数可能不同。

出版社的 `+`/`+=` 实现假定 ISBN 相同，不替调用者拒绝不同 ISBN。本题源码主动检查，不同 ISBN 或不足两条记录时报告错误并以非零状态退出。

源码：[ex1_21.cpp](ex1_21.cpp)。

## 1.23：统计每个 ISBN 的记录条数

位置：1.5.2 节，书页 21 / PDF 页 47。

沿用 1.18 的连续分组方法，把比较整数改成比较 `item.isbn()`；相同时让记录计数加 1，换 ISBN 时输出旧组并重置。

```cpp
if (item.isbn() == current.isbn()) {
    ++count;
} else {
    std::cout << current.isbn() << " " << count << std::endl;
    current = item;
    count = 1;
}
```

这里统计的是**记录条数，不是销售册数**。一条售出 100 册的记录，只给条数加 1。

前提是同 ISBN 记录聚在一起。若输入按 A、B、A 排列，程序会输出三个组；不会自动把两处 A 合并。这里按本章的条件和循环实现，暂不提前使用关联容器。

源码：[ex1_23.cpp](ex1_23.cpp)。

## 1.25：完整书店程序

位置：1.6 节，书页 22 / PDF 页 48。题意：使用配套头文件，编译运行本节程序。

1.23 按组累计“条数”，这里按组累计 **`Sales_item` 销售汇总对象**。

```cpp
#include <iostream>
#include "Sales_item.h"

int main()
{
    Sales_item total;
    if (std::cin >> total) {
        Sales_item transaction;
        while (std::cin >> transaction) {
            if (total.isbn() == transaction.isbn()) {
                total += transaction;
            } else {
                std::cout << total << std::endl;
                total = transaction;
            }
        }
        std::cout << total << std::endl;
    } else {
        std::cerr << "No data!" << std::endl;
        return -1;
    }
    return 0;
}
```

以 [grouped_sales.txt](data/grouped_sales.txt) 为输入，预期输出：

```text
0-201-70353-X 5 120 24
0-201-78345-X 5 110 22
0-201-82470-1 1 30 30
```

处理过程：第一条建立 `total`；同 ISBN 时累加；换 ISBN 时先输出旧书总计，再用新记录覆盖 `total`；最后补输出末组。

本章程序要求同 ISBN 数据相邻。空输入把 `No data!` 写到标准错误并返回 `-1`；单条输入直接输出该条的销售汇总。

源码：[ex1_25.cpp](ex1_25.cpp)。
