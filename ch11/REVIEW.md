# 第 11 章复习提纲

结合 [第 11 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 容器 | 典型用途 | 关键约束 |
| --- | --- | --- |
| `map` | 键值查找与计数 | 关键字需支持 `<`（有序版）或哈希与 `==`（无序版） |
| `set` | 只关心存在性、去重 | 无映射值，不支持下标 |
| `multimap` / `multiset` | 一键多值 | `insert` 总是成功，`equal_range` 定位范围 |
| `unordered_*` | 平均常数时间查找 | 元素无序，自定义哈希需自备 |

## 自测

- [ ] 解释 `m[k]` 在关键字不存在时做了什么，以及它与 `m.at(k)` 的差别。
- [ ] 说明 `insert` 返回的 `pair<iterator, bool>` 如何用于单词计数。
- [ ] 对 `map` 的迭代器指出哪个成员可写、哪个不可写及原因。
- [ ] 用 `find` 与 `erase` 的返回值删除 multimap 中一个作者的全部条目。
- [ ] 举出应选有序容器与无序容器的两个场景。
