# 第 3 章复习提纲

结合 [第 3 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 工具 | 关键点 | 易错 |
| --- | --- | --- |
| `string` | 长度可变，`==` 与 `<` 按内容比较 | 下标越界未定义；`c_str()` 的指针随修改失效 |
| `vector` | 动态增长，`==` 按元素比较 | 空向量不能下标赋值；range-for 内不要改变大小 |
| 迭代器 | `begin/end`、`cbegin/cend` | 迭代器不支持 `<`，只支持 `!=` 与递增 |
| 数组 | 大小是类型的一部分，不能拷贝赋值 | 函数内未初始化元素值未定义 |
| 指针与数组 | 数组名常退化为首元素指针 | 只能加减整数或相减，不能相加 |
