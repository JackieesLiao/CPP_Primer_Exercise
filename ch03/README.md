## 3.1 using 声明

第 1 章的每个程序把 `using std::cin;`、`using std::cout;`、`using std::endl;` 移到 `main` 之前即可去掉 `std::` 前缀，其余逻辑不变；示例代码已在 [ch01](../ch01/README.md) 验证过。

## 3.2 逐行与逐词读入

[ex3_02.cpp](ex3_02.cpp) 先用 `getline` 读整行并回显，空行结束；再用 `>>` 逐词读入，`stop` 结束。`getline` 保留行内空格并丢弃换行符，`>>` 则以空白为界。

## 3.3 两种读取的差异

`string` 的 `operator>>` 跳过前导空白、在下一个空白处停止；`getline` 读到换行符为止并丢弃换行符。因此逐词读入拼句子需要自己补空格。

## 3.6–3.8 大写转换

## 3.9 非法下标

`string s; cout << s[0];` 中 `s` 为空，`s[0]` 越界，行为未定义。

## 3.10 去除标点

[ex3_10.cpp](ex3_10.cpp) 用 `ispunct` 过滤，把非标点字符追加到新串。输入 `hello, world!` 输出 `helloworld`。

## 3.11 const string 的 range-for

`c` 的类型是 `const char&`，可以读取但不能写，因此循环体里不能给 `c` 赋值。

## 3.12 vector 初始化的合法性

(a) `vector<vector<int>> ivec;` 合法；(b) `vector<string> svec(ivec);` 不合法，元素类型不同；(c) `vector<string> svec(10, "null");` 合法。

## 3.13 各 vector 的元素个数

(a) 0；(b) 10 个 0；(c) 10 个 42；(d) 1 个 10；(e) 10 个 0；(f) 10 个空串；(g) 10 个 `"hi"`。

## 3.18–3.19 快速构造元素

空 `vector` 不能用 `ivec[0] = 42` 赋值（越界），应先 `push_back(42)`。构造 100 个 42 可以写 `vector<int> ivec(100, 42);`，或先 `vector<int> ivec(100);` 再 `fill`，或循环 `push_back`。

## 3.25 成绩分段

[ex3_25.cpp](ex3_25.cpp) 用迭代器代替下标：`it += score / 10` 定位桶后递增。输入 `42 100 85 42 7 85` 输出 11 个桶的计数 `1 0 0 0 2 0 0 0 2 0 1`。输入假定在 0–100 之间，越界成绩会越过桶数组。

## 3.26 二分查找的迭代器运算

`end - beg` 是两个迭代器的差，结果是距离；`beg + end` 想把两个迭代器相加，迭代器不支持这种运算，只能 `beg + (end - beg) / 2`。

## 3.27 数组维度

维度必须是常量表达式：`unsigned buf_size = 1024; int ia[buf_size];` 不合法（`buf_size` 不是常量表达式），改成 `constexpr unsigned` 即可；字面量维度与 `constexpr` 维度都合法，`int ia[-4]`、维度为非常量函数返回值不合法。

## 3.28 默认初始化

函数外的 `int ia[10]` 为全 0，`string sa[10]` 为空串；函数内的 `int ia2[10]` 值未定义，`sa2[10]` 仍是空串。

## 3.29–3.30 数组与越界

数组大小固定、不能整块赋值或拷贝，也没有 `push_back`。3.30 中循环写到 `ia[10]`，越过了合法下标 0–9，属于未定义行为。

## 3.31–3.32 数组填充与拷贝

[ex3_31_32.cpp](ex3_31_32.cpp) 先写入 0–9，再逐元素复制到第二个数组。数组不能整体赋值，只能循环或 `std::copy`。

## 3.33 未初始化的计数数组

`scores` 不初始化时每个元素的值未定义，计数从垃圾值开始累加，结果不可信；应写 `unsigned scores[11] = {};`。

## 3.34 指针相加

`p1 += p2` 把 `p2` 的地址值当作偏移加到 `p1` 上，通常越出对象边界，语义错误且未定义；指针只能加减整数或相减求距离。

## 3.35–3.36 指针清零与数组比较

[ex3_35_36.cpp](ex3_35_36.cpp) 用 `std::begin/end` 得到数组边界，逐指针清零；再逐元素比较两个数组，先用长度差剔除不等的情况。两个 `vector` 可以直接 `==`，输出 `left == right: 1`、`left == other: 0`。

## 3.37 没有结束符的字符数组

`ca` 只有 5 个元素且不含 `'\0'`，循环一直推进直到碰巧遇到 0 字节，越过数组边界属于未定义行为。字符串字面量末尾自带 `'\0'`，逐字符初始化的数组没有。

## 3.38 指针相减

两个指针相减得到 `ptrdiff_t` 类型的距离，表示中间隔了几个元素；把地址值相加没有意义，因此标准库只提供指针减法。

[ex3_39.cpp](ex3_39.cpp) 用 `strcmp` 比较、`strcpy/strcat` 拼接，缓冲区按两串长度加 1 分配。MSVC 对这两个函数给出 C4996 弃用警告，本题正是练习它们，缓冲区边界已经正确计算。
