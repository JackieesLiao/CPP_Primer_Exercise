# 第 19 章复习提纲

结合 [第 19 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 工具 | 典型用途 | 易错 |
| --- | --- | --- |
| `allocator` | 分离分配与构造 | `deallocate` 的个数参数要与 `allocate` 一致 |
| RTTI | 运行期识别动态类型 | 指针返回空，引用抛 `bad_cast` |
| 成员指针 | 延迟绑定类成员 | 必须绑定对象，`.*` 与 `->*` 不同 |
| union | 一块内存多形态 | 非平凡成员要手工构造/析构 |
| `extern "C"` | 跨语言链接 | 不能修饰类成员 |
