## 编译第一章

原项目使用 CLion + CMake。第一章提供独立 CMake 配置，可在 CLion 中打开 `ch01`，或在已配置编译器的终端运行：

```powershell
cmake -S ch01 -B build/ch01
cmake --build build/ch01 --config Debug
```

可执行文件的位置取决于生成器：例如 Visual Studio 通常在 `build/ch01/Debug`，单配置生成器通常直接放在 `build/ch01`。

也可以单独编译，具体命令见第一章的环境说明。
