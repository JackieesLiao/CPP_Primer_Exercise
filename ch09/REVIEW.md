# 第 9 章复习提纲

结合 [第 9 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 选择 | 典型理由 | 注意 |
| --- | --- | --- |
| `vector` | 随机访问、尾部追加、连续存储 | 中间插入删除可能移动元素，扩容可能使所有迭代器失效 |
| `deque` | 两端插入删除 | 迭代器失效规则与 `vector` 不完全相同 |
| `list` / `forward_list` | 已知位置附近频繁插入删除 | 不支持随机访问；定位元素仍可能需要遍历 |
| `array` | 长度固定 | 长度是类型的一部分，不能增删元素 |

## 自测

- [ ] 说明 `size` 与 `capacity` 的区别，解释 `reserve` 不会创建新元素。
- [ ] 删除迭代器指向的元素后，使用 `erase` 返回值继续遍历。
- [ ] 查阅具体容器规则，判断插入、删除后迭代器与引用是否仍有效。
- [ ] 对比 `string::find` 返回的 `npos` 和索引 0。
- [ ] 解释 `stack`、`queue`、`priority_queue` 对底层容器提供的接口限制。
