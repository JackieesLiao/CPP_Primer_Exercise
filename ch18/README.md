# 第 18 章：用于大型程序的工具

已核对并整理 18.1–18.32（书页 790–860 / PDF 页 816–886）。知识复习见 [复习提纲](REVIEW.md)。

## 18.1–18.11 异常处理

18.1 的表达式中 `*v.begin()` 解引用尾后未定义、`v[0]` 与 `v.at(0)` 在空 vector 上分别未定义和抛 `out_of_range`；18.2 中 vector 扩容抛 `bad_alloc`，栈展开销毁对象但不释放堆资源，应改用智能指针或显式清理（18.3）；18.4/18.5 的 catch 匹配按"最佳匹配"进行，`catch(...)` 捕获一切且 `throw;` 重新抛出当前异常（18.11）。[ex18_06_08.cpp](ex18_06_08.cpp) 依次抛出 18.6 的四类异常并逐个捕获；`FileGuard` 是 18.8 的 RAII 答案——离开作用域时析构关闭文件，异常路径同样有效。18.9 要求异常类型的拷贝/析构不得抛出；18.10 中未捕获的异常调用 `std::terminate`。

## 18.12–18.20 命名空间

18.12/18.15/18.16/18.17 的合法性与全局声明搬移属于编译检查；18.13 见 [ex18_13_18.cpp](ex18_13_18.cpp)：匿名命名空间的计数器具有内部链接，等价于 C 的 `static`；18.14 说明头文件里写 `using` 会污染所有包含者；18.18 的 `widget_swap` 用 `using std::swap;` 后，类专属 `swap(Widget&, Widget&)` 经实参相关查找优先命中，这正是惯用法；18.19/18.20 的重载集合见 [ex18_20.cpp](ex18_20.cpp)——引入 `using A::f` 后 `f(10)` 命中 `A::f(int)`（精确匹配胜过 `B::f(double)` 的转换），再加入 `B::f` 结果不变。

## 18.21–18.28 多重继承

[ex18_21_24.cpp](ex18_21_24.cpp) 中派生类指针不能转换为私有基类（注释保留）；Panda 从 Bear 与 Endangered 两路继承，三个基类指针都能指向它并访问各自的成员。18.22/18.23 的构造图按虚基类→直接基类（从左到右）→自身进行。18.26 的 `print(42)` 在两个基类同名同签名时产生二义；[ex18_26_27.cpp](ex18_26_27.cpp) 的 `MI::print(int)` 显式转发 `Base1::print` 消除二义，18.27 的 `using Base1::print; using Base2::print;` 是另一种修法。18.28：不同基类的同名数据成员也要用限定名访问。

## 18.29–18.32 虚基类

[ex18_29_30.cpp](ex18_29_30.cpp) 的输出完全对应 18.29 的答案：`VirtualBase → VD1 → VD2 → Final` 构造，析构严格逆序；`Final` 的构造函数负责初始化共享虚基。18.31 讨论拷贝与赋值在虚基下的行为，18.32 讨论虚基数据的封装路径。
