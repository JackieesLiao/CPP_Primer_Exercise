# 第 10 章复习提纲

结合 [第 10 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 工具 | 典型用途 | 注意 |
| --- | --- | --- |
| 只读算法（`find`、`count`、`accumulate`） | 查找与统计 | 用 `cbegin/cend` 表明不修改元素 |
| 重排算法（`sort`、`unique`、`partition`） | 整理序列 | 算法不改容器大小，`unique` 后需 `erase` |
| 定制操作（lambda、`function`、`bind`） | 传递谓词与比较器 | 按值捕获复制对象，按引用捕获注意生命周期 |
| 插入迭代器（`back_inserter` 等） | 让写算法创建元素 | `front_inserter` 得到逆序，`inserter` 从指定位置前插入 |
| 流迭代器（`istream_iterator` 等） | 把流当作序列 | 绑定流后用 `++` 读取，流失效即尾后 |
| 反向迭代器（`rbegin` 等） | 逆序遍历与查找 | `base()` 指向原元素的下一个位置 |

## 自测

- [ ] 解释 `accumulate` 第三个实参如何决定和的类型，并预测一个会截断的例子。
- [ ] 写出 `sort` + `unique` + `erase` 三步消重，说明为什么 `unique` 之后必须 `erase`。
- [ ] 区分 `find_if`、`partition`、`stable_partition` 的返回范围各指哪一段。
- [ ] 说明 lambda 捕获列表中按值、按引用与 `mutable` 的语义差异。
- [ ] 用 `bind` 和占位符重排一个函数的实参顺序，并指出占位符所在命名空间。
- [ ] 判断一段代码里插入迭代器、流迭代器或反向迭代器各自的适用场景。
- [ ] 说出五种迭代器类别及各自支持的运算，举出每类的一个容器或算法。
