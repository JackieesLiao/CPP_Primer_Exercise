# 第 8 章：IO 库

本章习题为 8.1–8.14，按本地中文版第五版书页 281、285、287、289 核对。PDF 页码分别为 307、311、313、315。

## 8.1 从输入流读取并输出

[ex8_01.cpp](ex8_01.cpp) 接受并返回 `std::istream&`，逐个读取单词并输出，读取失败后调用 `clear()` 清除流状态。流对象不可复制，因此使用引用。`clear()` 重置状态位，但不会从输入中删除导致格式错误的字符，也不会自动让已到达结尾的数据源产生新数据。

## 8.2 用 cin 测试

源码的 `main` 使用 `std::cin` 调用函数。输入 `one two` 后结束输入，输出两行 `one` 和 `two`。Windows 交互终端一般使用 Ctrl+Z 再按 Enter；也可从文件或管道提供输入。

## 8.3 输入循环什么时候结束

`while (std::cin >> i)` 在提取失败时结束，包括遇到文件结束、输入不符合 `i` 的类型、或发生严重 IO 错误；读取成功且值为 0 不会结束循环。

## 8.4 按行读取文件

[ex8_04.cpp](ex8_04.cpp) 用 `getline` 将每一行放入一个 `vector<string>` 元素，空行也保留。打开失败抛出异常，调用处报告错误。

## 8.5 按单词读取文件

[ex8_05.cpp](ex8_05.cpp) 改用 `input >> word`。提取运算符以空白分隔，连续空格和换行不会产生空单词；原来的行边界也不会保留。

## 8.6 文件输入的书店程序

[ex8_06_07_08.cpp](ex8_06_07_08.cpp) 接受输入文件路径，读取 ISBN、册数、单价，输出每个连续 ISBN 分组的总册数、总金额和均价。同 ISBN 记录需要相邻。第一条记录建立累计对象，换组及结束时输出，避免漏掉最后一组。

## 8.7 输出到指定文件

同一程序接受第二个路径作为输出文件。默认 `ofstream` 输出会截断已有内容，使用前应确认输出路径；输出文件应与输入文件不同。命令形式：`program input.txt output.txt`。

## 8.8 追加输出

运行 `program input.txt output.txt --append`，以 `ios::app` 打开输出文件。连续运行两次后，输出中应有两份汇总。`app` 的每次写入定位到文件末尾；`ate` 只是打开时先定位到末尾，语义不同。

此示例使用格式化提取，遇到格式错误会停止；如果不完整记录恰好以 EOF 结束，当前版本可能把它当作普通结束。需要严格校验时，应逐行读取并检查每一行恰有三个字段。

## 8.9 用 istringstream 调用 8.1

[ex8_09.cpp](ex8_09.cpp) 将字符串流传给接受 `istream&` 的函数。它逐行输出 `one`、`two`、`three`。`istringstream` 可作为输入流使用；`clear()` 清除状态，不会把读取位置移回开头。

## 8.10 先保存行，再解析单词

[ex8_10.cpp](ex8_10.cpp) 先使用 `getline` 保存整行，再为每行构造 `istringstream` 并读取单词。空行在第一阶段保留，在第二阶段不会产生单词。

## 8.11 在循环外复用字符串流

[ex8_11.cpp](ex8_11.cpp) 每次处理新行时先 `record.clear()`，再用 `record.str(line)` 替换缓冲内容。只替换字符串而不清除上轮读取失败留下的状态，后续提取可能立即失败。空行跳过，非空行首个单词为姓名，余下的是电话号码。

## 8.12 为什么 PersonInfo 不需要类内初始化

两个成员分别为 `string` 和 `vector<string>`，它们默认构造时分别为空字符串和空容器，因此无需显式类内初值。内置数值类型成员则不能据此假定已经初始化。

## 8.13 从文件读取电话号码

[ex8_13.cpp](ex8_13.cpp) 从文件读行、解析姓名和号码，先在字符串流中收集格式化结果及无效号码，再决定输出或报错。书中没有定义号码验证规则，此实现仅为练习设定“恰好十个 ASCII 数字”并格式化为 `xxx-xxx-xxxx`；它不是通用电话号码校验器。存在无效号码时该人的结果写入标准错误。

## 8.14 为什么使用 const auto&

遍历时只读取人员对象与号码，`const` 防止意外修改，引用避免复制对象和字符串。值类型的 `auto` 通常也能工作，但会复制；如果需要修改原元素，则不能使用 `const`。
