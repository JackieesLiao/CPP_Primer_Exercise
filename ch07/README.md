## 7.1 交易处理程序

使用第二章的 `Sales_data` 数据成员，将同 ISBN 的连续销售记录汇总。输入每行是 ISBN、册数、单价；程序按 ISBN 连续分组，输出 ISBN、册数、销售额和平均售价。数据必须按 ISBN 聚集；循环结束时单独输出最后一组。参见 [ex7_01.cpp](ex7_01.cpp)。

## 7.2 增加成员函数

[Sales_data.h](Sales_data.h) 提供 `isbn() const` 和 `combine(const Sales_data&)`。`isbn` 不修改当前对象，因此标记为 `const`；`combine` 更新册数与销售额后返回 `*this` 的引用。调用者负责确保 ISBN 相同。

## 7.3 使用新增接口

[ex7_03.cpp](ex7_03.cpp) 用 `isbn()` 比较、用 `combine()` 汇总。两个版本都以连续的同 ISBN 记录为一组。

## 7.4–7.5 Person 与常量成员函数

[Person.h](Person.h) 用两个 `std::string` 存储姓名和地址，并提供读取函数。读取函数不改变对象，应声明为 `const`，使常量对象也能调用。这里返回字符串副本，避免让调用方持有指向对象内部数据的引用。

## 7.6：实现 add、read 和 print

[Sales_data_io.h](Sales_data_io.h) 定义三个非成员函数。`read` 接受输入流和可修改对象，成功读取后计算销售额；`print` 计算均价并返回输出流；`add` 复制左侧对象，再合并右侧对象，调用者应确保 ISBN 相同。头文件中的非成员函数使用 `inline`，避免多个翻译单元包含它时产生重复定义。

## 7.7：使用非成员函数重写交易程序

[ex7_07.cpp](ex7_07.cpp) 使用 `read` 读取记录并用 `print` 输出。数据仍要求同 ISBN 相邻；空输入返回非零。每次 ISBN 变化输出旧组，循环结束输出末组。

## 7.8：read 与 print 的引用为何不同

`read` 需要修改对象，因此使用 `Sales_data&`；`print` 只读取对象，使用 `const Sales_data&`，既避免复制又允许传入常量对象。流本身会改变状态，因而流参数不能是常量引用。

## 7.9：Person 的输入输出

[Person_io.h](Person_io.h) 添加 `read` 和 `print`。本例使用空白分隔姓名与地址，适合单词形式的输入；含空格的完整地址需要另行设计格式，例如逐行读取。

## 7.10：嵌套 read 的条件

`read(read(cin, data1), data2)` 先读取第一条，再把返回的同一个流传给外层读取第二条。整个表达式返回该流，`if` 检查第二次读取后的流状态；第一次读取失败时流已失败，第二次也无法正常提取。
