# 第 16 章复习提纲

结合 [第 16 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 主题 | 关键点 | 易错 |
| --- | --- | --- |
| 函数模板 | 实参推导实例化 | 元素类型的运算符必须可用 |
| 类模板 | 使用处给实参，类内可省 | `typename` 标注依赖类型 |
| 重载与特化 | 非模板精确匹配优先 | 特化不是重载，可能永远不命中 |
| 可变参数模板 | 递归展开参数包 | 转发要用 `std::forward` |
| 模板特化 | `std::hash` 等定制点 | 特化必须与原模板同一作用域 |

## 自测

- [ ] 解释 `debug_rep("hi")` 为什么选中指针版本。
- [ ] 用可变参数模板实现至少两个参数的 print 并说明终止条件。
- [ ] 为一个类特化 `std::hash` 并放进 unordered 容器验证。
