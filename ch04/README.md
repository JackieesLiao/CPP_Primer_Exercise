# 第 4 章：表达式

已核对并整理 4.1–4.35（书页 134–180 / PDF 页 160–206）。知识复习见 [复习提纲](REVIEW.md)。

## 4.1–4.5 表达式求值

4.1 的 `5 + 10 * 20 / 2` 中 `20 / 2` 先算，得 105。4.2 加括号：`((12 / 3) * 4) + (15 % 6)` = 16 + 3 = 19。4.5：(a) -86；(b) -210；(c) 0；(d) -2。C++11 规定商向零取整，因此 `-21 / 5 = -4`、`-21 % 5 = -1`，余数的符号跟随被除数。

## 4.3 求值顺序

`f() + g() * h()` 中只有 `*` 优先于 `+`，三个函数的调用顺序是未指定的。依赖求值顺序的表达式（如 `cout << i << ++i`）不可移植。

## 4.6–4.6 奇偶判断

[ex4_06_21_22.cpp](ex4_06_21_22.cpp) 用 `value % 2 != 0` 判断奇数：负奇数的余数是 -1 而非 1，所以不能用 `== 1`。

## 4.7 溢出

`short` 相乘、`int` 累加超出范围、最大 `int` 再加 1 都会溢出。有符号整数溢出是未定义行为，无符号则是取模回绕。

## 4.8–4.9 逻辑运算的短路

`&&` 与 `||` 保证左操作数先求值且右侧可能被跳过：`if (p && *p)` 先判空再解引用。`is_empty(s) || s.size() > 0` 之类写法可以安全依赖这一顺序。

## 4.10 循环条件

`while (std::cin >> i && i != 42)` 读到 42 即停止，且只有读取成功才比较。

## 4.11–4.12 关系与相等运算

连续比较 `a > b > c` 先算 `a > b` 得到 bool，再与 `c` 比较，语义几乎总是错的；应写 `a > b && b > c`。`i != j < k` 因 `<` 优先级高于 `!=`，等价于 `i != (j < k)`。

## 4.13 赋值链

`i = f = j = 3.4`：`f` 得 3.4，`i` 得 3；`d = i = j = 3.5`：`i` 得 3，`d` 得 3.0。

## 4.14–4.16 常见的 = / == 混用

`if (12 = i)` 不合法（右值不能被赋值）；`if (i = 42)` 合法且恒真，是漏写 `=` 的典型错误。4.16(a) `if (p = getPtr() != 0)` 实际是 `p = (getPtr() != 0)`，应为 `if ((p = getPtr()) != 0)`；(b) `if (i == 1024)` 若本意是赋值则漏了 `=`。

## 4.17–4.20 前置与后置递增

`++i` 返回递增后的对象，`i++` 返回旧值副本，因此能用 `++i` 就用 `++i`。4.18 中把 `*iter++` 改成 `*--iter` 会从最后一个元素向前处理并漏掉重排方向的意图。4.19 中 `grade = (grade == 100) ? ...` 等组合在本书答案语境下求值，但依赖同一表达式内的修改顺序仍然危险。4.20 中 `*it` 是元素，`(*it).empty()` 与 `it->empty()` 等价，`it->` 是 `(*it).` 的简写。

## 4.21–4.22 条件运算符

[ex4_06_21_22.cpp](ex4_06_21_22.cpp) 用 `is_odd(*it) ? *it * 2 : *it` 翻倍奇数位上的值；把成绩映射到 `high pass / pass / low pass / fail` 四档时，嵌套条件运算符的可读性明显差于 `if`，两个版本输出一致。

## 4.23 条件运算符与加法

`s + (s[s.size() - 1] == 's' ? "" : "s")` 需要括号：`+` 优先级高于 `?:`，原式把两段字符串与比较结果相加，无法编译。

## 4.24 嵌套条件的结合性

条件运算符右结合，`grade > 90 ? "high" : grade > 60 ? "pass" : "fail"` 等价于在 false 分支继续嵌套，据此可以确定 `a > b ? c : d > e ? f : g` 的分组。

## 4.25 位运算与优先级

`'q' << 6 | 3`：`<<` 优先级高于 `|`，先移位再按位或；若想先加 3 必须加括号。

## 4.26 quiz1 的位宽

旧版用 `unsigned long quiz1` 在 16 位平台上只有 16 位，容纳不下 30 个学生；C++11 起 `unsigned long` 至少 32 位，但用固定宽度的 `unsigned int quiz1 = 0`（32 位）更稳。

## 4.27–4.28 位运算与 sizeof

[ex4_27_28.cpp](ex4_27_28.cpp) 对 `3` 和 `7` 输出 `&` 为 3、`|` 为 7、`^` 为 4、`&&` 为 1（bool 提升后输出）。`sizeof` 的结果：本机 `char` 1、`int` 4、`long` 4、`double` 8、`string` 32、`vector<int>` 24。

## 4.29 sizeof 数组与指针

[ex4_29.cpp](ex4_29.cpp) 对 `int x[10]` 输出 10；对指针输出 `sizeof(p) / sizeof(*p)` = 8 / 4 = 2。数组名只在 `sizeof` 中不退化为指针，用指针冒充数组长度计算总是错的。

## 4.30 括号补充

`sizeof(x + y)` 中加法先于 sizeof 被括住；`sizeof(p->mem[i])` 取成员数组元素的大小；按意图补全括号即可消歧。

## 4.31–4.32 递增写法

`vec.size()` 是无符号数，`--end_idx` 在减到 0 后回绕成巨大值，循环条件 `idx != ivec.size()` 依赖后置递增的旧值比较，两种循环都能工作；书中练习的意图是展示前缀/后缀的差异。4.32 的 `ptr != end` 是指针作循环条件。

## 4.33–4.35 显式转换

4.33 的条件运算符两臂类型不同导致无法赋值，且混用 `++` 与条件运算符的写法本身就不可读。4.34：`if (i)` 转 bool；`d = i` 转 double。4.35：`'a' + 1` 提升 int；`cval = 'a' + 1` 截回 char；`ival = 1.9` 截断；无符号转换按模回绕。
