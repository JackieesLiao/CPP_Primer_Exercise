# 第 4 章复习提纲

结合 [第 4 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 主题 | 关键点 | 易错 |
| --- | --- | --- |
| 优先级与结合性 | `&&` 低于 `==`，条件运算符右结合 | 连续关系比较几乎总是错的 |
| 短路求值 | `&&`、`\|\|` 左侧先算，右侧可能跳过 | 不要依赖无顺序保障的混合求值 |
| 整数除法/取模 | 商向零取整，余数符号随被除数 | 负数取模不是 1 就是 -1，非零 |
| 位运算 | `&`、`\|`、`^`、`<<`、`>>` | 分清 `&` 与 `&&`，`<<` 优先级高于 `\|` |
| sizeof | 编译期字节大小，数组名不退化 | 用指针算数组长度永远不可靠 |
| 显式转换 | 命名转换优于 C 风格 | 有符号溢出未定义，转换窄化会截断 |
