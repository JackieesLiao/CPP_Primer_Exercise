# 第 17 章复习提纲

结合 [第 17 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 设施 | 典型用途 | 易错 |
| --- | --- | --- |
| `tuple` | 编译期异构序列 | 只能按位置访问，可读性不如 struct |
| `bitset` | 固定 N 位标志 | 初始化串的最高位对应最高下标 |
| `regex` | 文本校验与重排 | 组引用 `\\2` 约束分隔符一致性 |
| 随机数 | 分布 + 引擎分离 | 引擎播种决定可复现性 |
| 格式化 IO | `put_time`/`get_time` | 解析失败要检查流状态 |

## 自测

- [ ] 用 tuple 重写一个返回多值的函数，并说出 tuple 与 pair 的取舍。
- [ ] 解释 `bitset::count` 与 `size` 的区别并演示置位。
- [ ] 写出电话号码校验的正则并说明反向引用的作用。
- [ ] 生成一个指定范围、指定种子的随机序列并复现它。
- [ ] 用 `get_time` 解析日期并以自定义格式输出。
