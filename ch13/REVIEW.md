# 第 13 章复习提纲

结合 [第 13 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 操作 | 何时需要手写 | 关键写法 |
| --- | --- | --- |
| 拷贝构造 | 成员是裸资源 | 分配新资源再逐成员拷贝 |
| 拷贝赋值 | 同上 | 先分配后释放，保证自赋值安全 |
| 析构 | 成员持有裸资源 | 与拷贝/赋值成套出现 |
| 移动构造/赋值 | 类可受益于窃取资源 | `noexcept`，把源对象置为可析构状态 |
| swap | 交换远比拷贝便宜 | `using std::swap` 后交换成员 |
