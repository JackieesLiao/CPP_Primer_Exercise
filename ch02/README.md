# 第 2 章：变量和基本类型

## 2.1–2.2 基本类型的尺寸与选择

`int`、`long long`、`short` 与 `double` 的尺寸由实现决定：C++ 只保证 `int` 至少 16 位、`long long` 至少 64 位、`double` 是最常用的浮点类型。计算利率和本金应使用 `double`：`float` 通常只有 7 位有效数字，精度可能不够。

## 2.3–2.4 无符号运算的回绕

[ex2_03_04.cpp](ex2_03_04.cpp) 逐一输出书中的六个表达式：`42 - 10 = 32`；`10 - 42` 对无符号数按模 2³² 回绕，得到 4294967264；两个 `int` 相减得 -32；`i - u` 与 `u - i` 先把 `int` 转成 `unsigned` 再相减，都是 0。无符号回绕是有定义的行为，混用有符号与无符号时结果类型是无符号的，这是常见错误来源。

## 2.5–2.7 字面量的类型

| 字面量 | 类型 |
| --- | --- |
| `'a'` / `L'a'` / `"a"` / `L"a"` | `char` / `wchar_t` / 字符串字面量 / 宽字符串 |
| `10` / `10u` / `10L` / `10uL` / `012` / `0xC` | `int` / `unsigned` / `long` / `unsigned long` / 八进制 10 / 十六进制 12 |
| `3.14` / `3.14f` / `3.14L` | `double` / `float` / `long double` |
| `10` / `10u` / `10.` / `10e-2` | `int` / `unsigned` / `double` / `double` |

2.7 的 `"Who goes with F?\145 147\012"` 中，`\145` 是 `e`、`\147` 是 `g`、`\012` 是换行；`3.14e0L` 是 `long double`，`1024f` 是 `float`，`3.14L` 是 `long double`。

## 2.8 转义序列输出

[ex2_08.cpp](ex2_08.cpp) 用 `"2\x4d\012"` 打印 `2M` 加换行。十六进制转义 `\x` 与八进制转义 `\0` 都会尽量多读数字，`\x4d` 后面的反斜杠恰好终止了它。

## 2.9 初始化与赋值的错误

(a) `std::cin >> int input_value;` 在表达式里声明变量，不合法；应先声明再读入。(b) `int i = { 3.14 };` 列表初始化禁止窄化转换，编译错误。(c) `double salary = wage = 9999.99;` 中 `wage` 未声明，不合法。(d) `int i = 3.14;` 合法，`i` 被截断为 3。

## 2.10 默认初始化

函数外的 `global_str` 和 `global_int` 被值初始化为空串和 0；函数内的 `local_int` 未初始化，值未定义；`local_str` 无论位置都默认初始化为空串。

## 2.11 声明与定义

(a) `extern int ix = 1024;` 带初始化，实为定义（在函数外还会得到多余的 `extern` 警告）；(b) `int iy;` 是定义；(c) `extern int iz;` 是声明。

## 2.12 合法标识符

`int double = 3.14;`、`int catch-22;`、`int 1_or_2 = 1;` 不合法（保留字、连字符、数字开头）；`int _;` 与 `double Double = 3.14;` 合法。

## 2.13–2.14 作用域

2.13 中局部 `val` 遮蔽全局的 100，输出 100。2.14 中 `for` 的循环变量在独立作用域里，循环结束后外层 `i` 仍是 100，输出 `100 45`。

## 2.15–2.17 引用的约束

(a) `int &rval1 = 1.01;` 不合法，引用必须绑定到对象；(c) `int *&rval3 = iv;` 不合法，`int*` 的引用不能绑定到 `int`；(b)(d) 合法。引用一旦初始化就不能再改绑，对引用的赋值作用于被绑定的对象，因此 2.17 中 `ri = 10` 输出 10。

## 2.18 指针与指针所指

[ex2_18.cpp](ex2_18.cpp) 先经 `*pointer` 改写对象，再把 `pointer` 指向另一个对象并改写它。改变指针与改变所指对象是两个独立操作。

## 2.19–2.24 指针与引用的区别

- 引用必须初始化且不可改绑；指针是对象，可重新赋值、可以不指向任何对象。
- 2.20 中 `*p = *p * *p` 把 `i` 改成 1764。
- 2.21 中 `double *dp = &i;` 与 `int *p = i;` 类型都不匹配。
- 2.22 中 `if (p)` 判断指针本身非空，`if (*p)` 判断所指对象的值非零。
- 2.23 无法仅凭指针判断它是否指向有效对象；应保证初始化或用智能指针。
- 2.24 中 `void*` 可存放任意类型的地址，因为它不参与所指向对象的类型解释。

## 2.25 声明符的组合

(a) `int* ip, i, &r = i;` 中 `ip` 是 `int*`，`i` 是 `int`，`r` 是 `int&`——`*` 只修饰 `ip`；(b) `int i, *ip = 0;` 中 `i` 是 `int`，`ip` 是空指针；(c) `int* ip, ip2;` 中 `ip2` 是 `int`，不是指针。

## 2.26 const 对象

`const int buf;` 不合法（必须初始化）；`int cnt = 0;`、`const int sz = cnt;`、`++cnt;` 合法；`++sz;` 不合法。

## 2.27–2.29 底层与顶层 const

2.27 中合法的有：(b) `int *const p3 = &i2;`、(d) `const int *const p5 = &i2;`（`i2` 须为 `const int`）、(e) `const int &r5 = i2;`、(g) `const int i3 = i, &r6 = i3;`；不合法的是 (a)（引用必须绑定对象）与 (c)、(f)（绑定的是右值字面量且类型不符）。

2.28 中 (a)(b)(c)(d) 都不合法：`const` 指针或引用的 `const int` 未初始化；(e) `const int *p;` 合法。2.29 中只有 `i = ic;` 合法；给 `int*` 赋 `const int*`、给常量指针重新赋值、给 `const int` 赋值都不合法。

## 2.30–2.31 顶层与底层

`v2` 的 `const` 是顶层，`p2` 的 `const` 是底层加顶层（`const int *const`），`p3` 的 `const` 是底层。赋值时顶层 `const` 被忽略、底层 `const` 不能忽略：`v2 = v1` 合法，`p2 = p3` 合法（两边都是指向 `const int` 的指针），`p1 = p3`、`v1 = v2` 之后的 `p1 = &v2` 都要按底层规则判断。

## 2.32 int 与指针

`int null = 0, *p = null;` 不合法：`p` 需要地址，`null` 是 `int`。应写 `int null = 0, *p = nullptr;`。

## 2.33–2.38 auto 与 decltype

[ex2_33_38.cpp](ex2_33_38.cpp) 按书中的声明逐一推导并验证：`auto` 丢掉顶层 `const` 和引用，得到普通 `int`；`auto d = &i` 是 `int*`，`auto e = &ci` 是 `const int*`（底层 `const` 保留）；`auto &g = ci` 是 `const int&`。运行输出 `i 42, a 43, b 44, c 45` 说明 `a`、`b`、`c` 都是独立副本。`decltype(delta)` 是 `int`，`decltype((delta))` 是 `int&`——双重括号把变量变成表达式，得到左值引用。`auto` 由初始化的值推导并做常规转换，`decltype` 直接取表达式的声明类型而不求值。

## 2.39 缺少分号

类体结束后的分号是必须的，`struct Sales_data { ... }` 缺少分号会引发编译错误，错误信息往往指向下一处代码，不易定位。
