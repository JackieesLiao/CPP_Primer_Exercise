# 第 2 章复习提纲

结合 [第 2 章习题](README.md) 使用；本文件用于检查知识点，勾选应留给自己实际练习后完成。

| 概念 | 关键点 | 易错 |
| --- | --- | --- |
| 有符号/无符号 | 无符号按模回绕，有符号溢出未定义 | 不要用 `unsigned` 表达"非负"，混用会隐式转换 |
| 引用 | 初始化后不可改绑，是别名 | 必须绑定对象，不能绑定字面量 |
| 指针 | 可空、可改指向 | 使用前判断 `if (p)`，`void*` 不知所指类型 |
| 顶层 const | 对象本身只读，赋值时被忽略 | 底层 const 不可忽略，决定能否赋值 |
| auto | 丢顶层 const 和引用 | 想要 `const int&` 需显式写 `auto &g = ci` |
| decltype | 取表达式声明类型，不求值 | `(var)` 得到左值引用 |

- [ ] 对一段声明逐个指出顶层/底层 const。
- [ ] 解释 `auto` 与 `decltype` 的三个差异。
